# SDC · The Living Map — served build

Open `index.html`. Everything is fetched at runtime from `assets/`.

    ?scene=city      go straight to the district
    ?shot=1..6       jump to an authored bookmark
    ?seed=N          same world every reload
    ?walk=1          walk mode instead of fly
    ?nobl=1          turn the surface-law band-limiting OFF, for the A/B
    ?nolife=1        freeze the crowd, for pinned comparison shots

Controls: drag to look, WASD to move, shift to run, scroll to zoom on the map.
